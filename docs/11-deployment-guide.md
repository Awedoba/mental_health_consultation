# Deployment Guide

> **Version**: 1.0.0  
> **Last Updated**: December 2025

This guide provides step-by-step instructions for deploying the Mental Health Consultation Web App to production.

## Prerequisites

### System Requirements

- **Server**: Linux/Unix-based (Ubuntu 20.04+ recommended)
- **Web Server**: Nginx or Apache
- **PHP**: 8.3.28 or higher
- **Node.js**: 18.x or higher
- **Database**: PostgreSQL 12+ or MySQL 8.0+ (SQLite for development only)
- **SSL Certificate**: Required for HTTPS

### Required Software

- PHP extensions: `pdo`, `pdo_mysql`/`pdo_pgsql`, `mbstring`, `openssl`, `tokenizer`, `xml`, `ctype`, `json`, `bcmath`, `fileinfo`
- Composer (PHP package manager)
- pnpm (Node.js package manager)
- Git

## Backend Deployment

### 1. Server Setup

```bash
# Update system packages
sudo apt update && sudo apt upgrade -y

# Install PHP and required extensions
sudo apt install php8.3-fpm php8.3-cli php8.3-mysql php8.3-xml php8.3-mbstring php8.3-curl php8.3-zip php8.3-gd

# Install Composer
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

# Install Node.js and pnpm
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs
npm install -g pnpm
```

### 2. Clone Repository

```bash
cd /var/www
sudo git clone <repository-url> mental-health-consultation
sudo chown -R www-data:www-data mental-health-consultation
cd mental-health-consultation/backend
```

### 3. Install Dependencies

```bash
composer install --optimize-autoloader --no-dev
```

### 4. Configure Environment

```bash
cp .env.example .env
php artisan key:generate
```

Edit `.env` file:

```env
APP_NAME="Mental Health Consultation"
APP_ENV=production
APP_KEY=base64:... # Generated by key:generate
APP_DEBUG=false
APP_URL=https://your-domain.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=mental_health_db
DB_USERNAME=your_db_user
DB_PASSWORD=your_secure_password

SANCTUM_STATEFUL_DOMAINS=your-domain.com
SESSION_DOMAIN=your-domain.com
```

### 5. Database Setup

```bash
# Create database (if not exists)
mysql -u root -p
CREATE DATABASE mental_health_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'your_db_user'@'localhost' IDENTIFIED BY 'your_secure_password';
GRANT ALL PRIVILEGES ON mental_health_db.* TO 'your_db_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;

# Run migrations
php artisan migrate --force

# Seed initial data (optional)
php artisan db:seed --class=DatabaseSeeder
```

### 6. Configure Permissions

```bash
sudo chown -R www-data:www-data storage bootstrap/cache
sudo chmod -R 775 storage bootstrap/cache
```

### 7. Optimize Application

```bash
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache
```

### 8. Configure Nginx

Create `/etc/nginx/sites-available/mental-health-api`:

```nginx
server {
    listen 80;
    server_name api.your-domain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.your-domain.com;
    root /var/www/mental-health-consultation/backend/public;

    ssl_certificate /path/to/ssl/cert.pem;
    ssl_certificate_key /path/to/ssl/key.pem;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php;

    charset utf-8;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

Enable site:

```bash
sudo ln -s /etc/nginx/sites-available/mental-health-api /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## Frontend Deployment

### 1. Build Application

```bash
cd /var/www/mental-health-consultation/frontend
pnpm install
pnpm build
```

### 2. Configure Environment

Create `.env.production`:

```env
NUXT_PUBLIC_API_BASE=https://api.your-domain.com/api
```

### 3. Configure Nginx for Frontend

Create `/etc/nginx/sites-available/mental-health-app`:

```nginx
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com;
    root /var/www/mental-health-consultation/frontend/.output/public;

    ssl_certificate /path/to/ssl/cert.pem;
    ssl_certificate_key /path/to/ssl/key.pem;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api {
        proxy_pass https://api.your-domain.com;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

Enable site:

```bash
sudo ln -s /etc/nginx/sites-available/mental-health-app /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## Post-Deployment

### 1. Verify Deployment

- [ ] Frontend loads correctly
- [ ] API endpoints respond
- [ ] Authentication works
- [ ] Database connections successful
- [ ] SSL certificate valid

### 2. Set Up Monitoring

- Configure log rotation
- Set up error monitoring (e.g., Sentry)
- Configure uptime monitoring
- Set up database backups

### 3. Security Hardening

```bash
# Set secure file permissions
sudo find /var/www/mental-health-consultation -type f -exec chmod 644 {} \;
sudo find /var/www/mental-health-consultation -type d -exec chmod 755 {} \;

# Configure firewall
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable
```

### 4. Schedule Tasks

Add to crontab (`crontab -e`):

```cron
# Laravel scheduler
* * * * * cd /var/www/mental-health-consultation/backend && php artisan schedule:run >> /dev/null 2>&1

# Database backup (daily at 2 AM)
0 2 * * * mysqldump -u your_db_user -p'your_password' mental_health_db > /backups/db_$(date +\%Y\%m\%d).sql
```

## Maintenance

### Updating the Application

```bash
# Pull latest changes
cd /var/www/mental-health-consultation
sudo git pull origin main

# Backend
cd backend
composer install --optimize-autoloader --no-dev
php artisan migrate --force
php artisan config:cache
php artisan route:cache
php artisan view:cache

# Frontend
cd ../frontend
pnpm install
pnpm build

# Restart services
sudo systemctl restart php8.3-fpm
sudo systemctl reload nginx
```

### Database Backups

```bash
# Manual backup
mysqldump -u your_db_user -p'your_password' mental_health_db > backup_$(date +%Y%m%d_%H%M%S).sql

# Restore from backup
mysql -u your_db_user -p'your_password' mental_health_db < backup_file.sql
```

## Troubleshooting

### Common Issues

1. **500 Internal Server Error**
   - Check Laravel logs: `tail -f storage/logs/laravel.log`
   - Verify file permissions
   - Check PHP-FPM error logs

2. **Database Connection Errors**
   - Verify database credentials in `.env`
   - Check database server is running
   - Verify network connectivity

3. **Permission Denied Errors**
   - Check file ownership: `ls -la storage bootstrap/cache`
   - Fix permissions: `sudo chown -R www-data:www-data storage bootstrap/cache`

4. **API CORS Issues**
   - Verify `SANCTUM_STATEFUL_DOMAINS` in `.env`
   - Check CORS configuration in `config/cors.php`
